git clone

Embed the player

One script tag gives any web app, dashboard, IDE panel or agent harness a full player in the corner. Every song, synced lyrics, mood stations and Spotify playlists. The player below is it, mounted inline here. Leave out data-target and it floats in a corner instead.

Drop it in

<script src="/embed.js" data-station="lofi beats"></script>

Options: data-station, data-q, data-playlist, data-target (mount inside an element), data-position, data-open="false".

Drive it from code

hum.play('Blinding Lights')
hum.station('deep focus')
hum.playlist('https://open.spotify.com/playlist/…')
hum.pause()  hum.next()  hum.volume(60)
hum.on('state', s => console.log(s.track?.title))

Or as a plain iframe

<iframe src="/widget.html?station=lofi"
  width="360" height="520" allow="autoplay; encrypted-media"></iframe>

Talk to it with postMessage({ hum: 'play', query: '…' }). It reports back with { hum: 'state', … } messages.

For coding agents

Your agent is the remote. It can play a song, start a station, skip and set the volume, and the music plays in a hum tab through YouTube's own player. Needs Node 18 or newer, except for the Claude Desktop extension, which brings its own.

Add to Cursor Install in VS Code Claude Desktop extension

For the Claude Desktop extension, double-click the downloaded hum.mcpb file to install it. On VS Code Insiders, use this link.

Claude Code
claude mcp add --scope user hum -- npx -y -p github:anzal1/hum hum-mcp
From your terminal
# install once
npm i -g github:anzal1/hum
# play something
hum play lofi beats
# one line for status bars
hum now --line

Every other agent (Codex, Gemini CLI, Windsurf, Zed, Copilot CLI and more)

No MCP? The local server speaks plain HTTP too:

curl -X POST localhost:3737/api/remote \
  -H 'content-type: application/json' -d '{"cmd":"station","mood":"lofi"}'
